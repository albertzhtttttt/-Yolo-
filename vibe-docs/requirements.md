# 需求文档：基于 YOLO 模型的高分辨率遥感影像红树林林窗探测

**文档版本：** v1.2
**创建日期：** 2026-03-18
**项目目录：** `基于Yolo模型的高分辨率遥感影像红树林林窗探测/`

---

## 一、项目背景

红树林是重要的滨海湿地生态系统，林窗（Canopy Gap）是林冠层中自然或人为形成的开口区域，对红树林的生态动态和更新过程具有重要意义。利用高分辨率遥感影像（卫星与无人机）结合深度学习目标检测模型，可实现对红树林林窗的自动化、高精度探测。

## 三、原始数据集概况

### 3.1 训练数据（`data/orig_data/`）

分为两个**独立数据集**，分别训练**两个独立模型**，全部实验任务均在两个数据集上分别执行。

| 子集 | 图像数量 | 图像尺寸 | 格式 | 对应模型 |
|------|----------|----------|------|----------|
| 卫星影像（`satellite/`） | 34 张 | 256 × 256 | JPEG，RGB | **卫星模型** |
| 无人机影像（`uav/`） | 43 张 | ~1426 × 1161 | JPEG，RGB | **无人机模型** |

- 标注格式：YOLO 格式（`class_id cx cy w h`，归一化坐标）
- 目标类别：唯一类别 `0 → 林窗（Canopy Gap）`

### 3.2 预测数据（`data/predict/`）

用于训练完成后验证模型真实场景效果的大尺寸 GeoTIFF 文件，共 6 个位置：

| 位置文件夹 | TIF 文件 | 坐标系 | 附属文件 |
|------------|----------|--------|----------|
| `位置1/Level20/` | `pos1_now.tif` | WGS84（EPSG:4326） | `.prj`、`.tfw` |
| `位置2_1/Level20/` | `pos2_1.tif` | 同上 | 同上 |
| `位置2_2/Level20/` | `pos2_2.tif` | 同上 | 同上 |
| `位置2_3/Level20/` | `pos2_3.tif` | 同上 | 同上 |
| `位置3_1/Level20/` | `pos3_1.tif` | 同上 | 同上 |
| `位置3_2/Level20/` | `pos3_2.tif` | 同上 | 同上 |

> TIF 文件为 Big TIFF 格式，附带 `.tfw` 世界文件和 `.prj` 投影文件（WGS84），具备完整地理空间信息，支持地理坐标输出。每个位置还附有 `.kml` 文件标注任务范围。

## 五、项目阶段与任务分解

### 阶段一：数据处理、YOLOv8 训练、评估与大图预测

#### 任务 1.1：数据预处理与切片

**卫星数据（256×256）：**
- 图像尺寸较小，直接缩放至 640×640 送入模型
- 数据量较少（34 张），增强力度可适当加大

**无人机数据（~1426×1161）：**
- 使用**滑动窗口切片**生成 640×640 子块：
  - 切片尺寸：**640 × 640**（固定）
  - 步长：320（50% 重叠，避免目标被切断边界）
  - 同步裁剪并更新对应 YOLO 标注坐标
  - 过滤无目标的空白切片（可保留约 10% 负样本以抑制误检）

#### 任务 1.2：数据增强

对两个训练集分别执行以下增强操作（需同步变换标注框，仅对 train 集执行）：

| 增强类型 | 具体操作 |
|----------|----------|
| 几何变换 | 水平翻转、垂直翻转、随机旋转（0°/90°/180°/270°） |
| 尺度变换 | 随机缩放（±20%） |
| 色彩变换 | 亮度、对比度、饱和度随机抖动（HSV 调整） |
| 噪声/模糊 | 高斯噪声、随机模糊 |
| 混合策略 | Mosaic 拼接（4 图合一） |

#### 任务 1.3：构建 YOLO 格式数据集

两个独立数据集分别构建，目录结构：

```
data/
├── yolo_dataset_satellite/         # 卫星数据集
│   ├── images/train|val|test/
│   ├── labels/train|val|test/
│   └── dataset.yaml
└── yolo_dataset_uav/               # 无人机数据集
    ├── images/train|val|test/
    ├── labels/train|val|test/
    └── dataset.yaml
```

- 数据集划分比例：**train 70% / val 15% / test 15%**（按原始图像划分，切片后的子块归属随原始图像）
- `dataset.yaml`：`nc: 1`，`names: ['gap']`

#### 任务 1.4：YOLOv8 模型训练

两个数据集分别训练，互不干扰：

- 模型选型：`yolov8n` → `yolov8s` → `yolov8m`（由小到大尝试，独立选型）
- 固定输入尺寸：`imgsz = 640`
- 关键超参数（初始参考值，按实验结果调整）：
  - `epochs`: 100~200
  - `batch`: 16
  - `lr0`: 0.01，`lrf`: 0.01
  - `optimizer`: SGD 或 AdamW
  - `patience`: 50（早停）
  - `seed`: 42
- 使用预训练 COCO 权重进行迁移学习

> ⚠️ 代码将在实验室 GPU 服务器上运行，根据训练结果**反复迭代修改**，直至两个模型均达标。

#### 任务 1.5：模型评估与可视化（两个模型分别输出）

**评估指标：**
- Precision、Recall、mAP@0.5、mAP@0.5:0.95、F1-Score

**达标标准（参考）：**
- mAP@0.5 ≥ 0.70，无明显过拟合

**可视化输出（每个模型独立，美观）：**
- Loss 曲线（box/cls/dfl）+ mAP 曲线（随 epoch）
- 混淆矩阵
- PR 曲线、F1-Confidence 曲线
- 测试集预测结果可视化（原图 + 预测框 + 置信度）
- 数据集样本分布统计图

#### 任务 1.6：大尺寸 GeoTIFF 预测（地理信息输出）

**两个模型均对全部 6 个 TIF 大图进行推理**，流程如下：

**方案 A（优先尝试）：直接读取 GeoTIFF 地理坐标，输出矢量地理文件**

- 使用 GDAL / rasterio 读取 TIF 及 `.tfw` 地理变换参数
- 以 640×640 滑动窗口（步长 320）切片送入模型推理
- 将预测框的像素坐标反算为地理坐标（经纬度，WGS84）
- 输出格式：
  - **KML/KMZ 文件**：每个林窗对应一个 Placemark，可在 Google Earth 叠加显示
  - **SHP 文件**：Shapefile 格式，含几何多边形框和属性（置信度、来源位置）

**方案 B（备用方案，方案 A 不可行时使用）：切片预测 + 收集检测图片**

- 将 TIF 按 640×640 切片（步长 320）保存为 JPEG
- 逐片推理，将**含有林窗检测框的切片**连同预测可视化结果收集到输出文件夹
- 输出结构：

```
results/phase1_predict/
├── satellite/                      # 卫星模型的预测结果
│   ├── 位置1/
│   │   ├── detected_tiles/         # 含检测结果的切片（带标注框）
│   │   └── summary.txt             # 统计信息（切片总数、检测数、置信度分布）
│   └── ...
└── uav/                            # 无人机模型的预测结果
    └── ...
```

> 优先执行方案 A；若依赖库安装困难或坐标精度有问题，回退至方案 B，代码注释中说明。

### 阶段二：分辨率影响分析

**前提：** 两个模型的阶段一均达标。

**目标：** 研究空间分辨率变化对两种来源影像林窗探测性能的影响规律（两个数据集分别分析）。

#### 任务 2.1：多分辨率数据集构建（两套）

- 对卫星和无人机原始图像分别进行**双线性插值下采样**，构建分辨率梯度：
  - 原始分辨率（基准 100%）
  - 降采样至 75%、50%、25%（再统一缩放回 640×640 送入模型）
- YOLO 归一化标注坐标直接复用（不受分辨率变化影响）

#### 任务 2.2：控制变量训练与测试（两套）

- 对每个数据集、每个分辨率级别，**保持相同模型结构与超参数**
- 独立训练并在对应测试集评估
- 记录各分辨率下的全套指标

#### 任务 2.3：分辨率影响可视化（两套，可对比展示）

**可视化输出（美观）：**
- 各指标随分辨率变化折线图（卫星/无人机并排或叠加展示）
- 不同分辨率下同一区域检测结果对比图
- 分辨率与目标尺寸分布关联散点图

### 阶段三：对比实验

**前提：** 两个模型的阶段一均达标。

**目标：** 在两个数据集上分别将 YOLOv8 与其他主流模型进行横向对比。

#### 对比模型

| 模型 | 类型 | 说明 |
|------|------|------|
| **YOLOv5** | 目标检测（one-stage） | 量化版本提升效果 |
| **U-Net** | 语义分割 | YOLO 框转掩码训练，后处理提取实例框 |
| **FCN** | 语义分割 | 全卷积网络基线，同 U-Net 标注转换策略 |

#### 任务 3.1~3.3：训练、评估与可视化（两套）

- 两个数据集分别执行完整对比实验
- 统一评估指标（Precision / Recall / mAP / F1 / FPS / Params / FLOPs）
- **可视化输出（美观）：**
  - 各模型指标对比柱状图（卫星 / 无人机分别一组）
  - 速度 vs. 精度散点图
  - 典型测试图像各模型预测结果横向对比拼图
  - 综合性能雷达图

## 六、代码规范要求

1. **详细中文注释**：每个函数、类、关键逻辑均需注释，说明功能、参数、返回值
2. **模块化结构**：数据处理、训练、评估、预测、可视化分别独立脚本；卫星和无人机通过参数切换，不重复编写

5. **美观可视化**：图表统一风格（matplotlib + seaborn），支持中文字体，分辨率 ≥ 300 DPI
